# Matemáticas 9°

- **Grado:** 9° (noveno)
- **Slug:** `matematicas-9`
- **Intensidad sugerida:** 5 h/semana
- **Referentes:** Estándares 8°–9°, DBA Matemáticas 9°.

## Descripción

El curso estudia las funciones lineales, cuadráticas, exponenciales y logarítmicas, y los sistemas de ecuaciones. Cierra con sucesiones, semejanza y probabilidad.

## Lecciones
