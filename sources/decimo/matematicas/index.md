# Trigonometría y Geometría Analítica

- **Grado:** 10° (décimo)
- **Slug:** `matematicas-10`
- **Intensidad sugerida:** 4 h/semana
- **Referentes:** Estándares 10°–11°, DBA Matemáticas 10°.

## Descripción

El curso estudia las razones y funciones trigonométricas, las identidades, las ecuaciones y la resolución de triángulos. Cierra con las cónicas y el análisis de datos bivariados.
