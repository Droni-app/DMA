# Inglés 11°

- **Grado:** 11° (once)
- **Slug:** `ingles-11`
- **Intensidad sugerida:** 3 h/semana

## Descripción

El curso consolida los tiempos verbales y el estilo indirecto, y trabaja la escritura académica. Termina con una preparación específica para cada parte de la prueba de inglés Saber 11.
